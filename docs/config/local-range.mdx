# local_range

:::warning

`local_range` was removed in Nebula v1.9.0 and is ignored if set. Use
[`preferred_ranges`](/docs/config/preferred-ranges/) instead.

:::

`local_range` was used to define a hint about the local network range, which speeds up discovering the fastest path to a
network adjacent nebula node.

```yml
local_range: '172.16.0.0/24'
```
